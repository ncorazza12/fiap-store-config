# Comparação Pod Security Admission (PSA)

A comparação entre os namespaces demonstra as diferentes camadas de proteção oferecidas pelo Kubernetes. No namespace `store-seguro` (perfil `restricted`), a rejeição do Pod privilegiado foi abrangente, listando múltiplas violações das melhores práticas de segurança, como a falta da restrição de usuário (`runAsNonRoot`), o risco de escalonamento de privilégios e a ausência do descarte de *capabilities*. Já no namespace `store-legado` (perfil `baseline`), que é desenhado para ser mais permissivo e aceitar workloads comuns, o Pod também foi bloqueado, porém o erro apontou exclusivamente a violação da flag `privileged: true`. Isso comprova que, enquanto o `restricted` impõe o endurecimento total do container, o `baseline` atua como uma rede de segurança mínima, proibindo vulnerabilidades críticas conhecidas, mas sem exigir configurações avançadas de hardening.
